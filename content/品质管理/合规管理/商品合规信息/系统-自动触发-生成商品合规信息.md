# 系统-自动触发-生成商品合规信息

### 业务规则

系统根据商品与目的国关系生成、删除或废弃商品合规信息。

触发条件：
合规确认节点开始时，系统按所有已绑定的 Msku+目的国生成商品合规信息。
合规确认节点开始后，新增绑定的 Msku+目的国时，系统生成商品合规信息。
合规确认节点开始后，重新停用再启用商品时，系统生成商品合规信息。
产品管理新建 Msku+目的国时，系统生成商品合规信息。
产品管理将 Msku+目的国从「停售」变更为「在售」时，系统生成商品合规信息。

取值逻辑：
【数据维度】goods id 维度
【Msku】取自商品绑定关系
【目的国】取自商品绑定关系
【状态】默认「待处理」
【合规标签状态】默认「待处理」
【合规报告状态】默认「待处理」
【需求创建时间】系统生成商品合规信息的时间

### 删除与废弃

合规确认节点开始后删除 sku 时，系统删除对应商品合规信息。
合规确认节点开始后解绑同 Msku 目的国下所有销售国时，系统删除对应商品合规信息。
合规确认节点开始后，在开发产品管理停用 Msku+销售国时，系统将商品合规信息状态变更为「已废弃」。
产品管理将 Msku+目的国从「在售」变更为「停售」时，系统将目的国名下所有商品合规信息状态变更为「已废弃」。

### 异常场景

同一 goods id 已存在商品合规信息时是否重复生成待确定。
上游缺少【Msku】或【目的国】时是否生成待确定。

### 通过校验后执行

执行1：生成、删除或更新商品合规信息。
执行2：记录操作日志。
