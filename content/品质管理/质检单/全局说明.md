# 质检单-全局说明

### 状态变更
大货质检单

```mermaid
stateDiagram-v2
    [*] --> 待质检 : 新建/生成
    待质检 --> 待审批 : 提交质检且触发审批
    待质检 --> 已废弃 : 废弃
    待审批 --> 已完成 : 审批通过
    待审批 --> 已驳回 : 审批不通过
    已驳回 --> 待审批 : 重新完成质检且触发审批
    已驳回 --> 已废弃 : 废弃
    已完成 --> [*]
    已废弃 --> [*]
```

新品质检单

```mermaid
stateDiagram-v2
    [*] --> 待质检 : 新建
    待质检 --> 已完成 : 完成质检，是否需要审批待确定
    待质检 --> 已废弃 : 废弃
    已完成 --> [*]
    已废弃 --> [*]
```

### 状态与操作对照
大货质检单

| 状态 | 可执行的操作 |
| --- | --- |
| 所有状态 | 详情 |
| 待质检 | 质检、修改质检排期、废弃 |
| 已驳回 | 完成质检、修改质检排期、废弃 |
| 待审批 | 审批、废弃 |
| 已完成 | 打印 |
| 已废弃 | - |

新品质检单

| 状态 | 可执行的操作 |
| --- | --- |
| 所有状态 | 详情 |
| 待质检 | 质检、修改质检排期、废弃 |
| 已废弃 | - |
| 已完成 | - |
