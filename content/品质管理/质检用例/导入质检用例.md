
| 字段   | 是否必填 | 导入时的逻辑判断                              | 导入报错的提示内容  |
| ---- | ---- | ------------------------------------- | ---------- |
| 质检类型 | 是    | 判断质检类型是否为对应字典管理里面启用的字段                | 质检类型信息错误   |
| 测试内容 | 是    | 判断字符是否满足限制100位字符                      | 测试内容字符数超标  |
| 检验用途 | 是    | 字符是否符合选项的字段：样品评估、大货质检                 | 检验用途填写内容错误 |
| 检验工具 | 是    | 判断字符是否满足限制100位字符                      | 检验工具字符数超标  |
| 缺陷等级 | 是    | 字符是否符合选项的字段：MAJ、CRI、MIN               | 缺陷等级填写内容错误 |
| 测试方法 | 否    | 判断字符是否满足限制500位字符                      | 测试方法字符数超标  |
| 判断准则 | 否    | 判断字符是否满足限制500位字符                      | 判断准则字符数超标  |
| 产品分类 | 否    | 判断质检类型是否为对应产品分类的字段，格式举例：收纳类/塑料收纳筐/pp筐 | 产品分类填写内容错误 |
| 用例状态 | 否    | 字符是否符合选项的字段：启用、停用                     | 用例状态填写内容错误 |
