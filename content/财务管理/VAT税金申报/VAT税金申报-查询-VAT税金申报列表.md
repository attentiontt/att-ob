# VAT税金申报-查询-VAT税金申报列表

### 列表数据

基础信息
【编号】列表展示字段，取 VAT税金申报记录编号或列表序号，具体口径待确定
【运单号】头程发货单数据
【头程发货单号】头程发货单数据
【物流专员】头程发货单数据
【国家】头程发货单目的国
【币种】目的国对应的币种代码
【VAT申报主体】拆分时匹配到的 VAT申报主体，展示【公司英文名称】
【店铺】拆分后的店铺，以标签形式展示，多个店铺展示多个标签
【箱数】拆分后的【实际装柜数】/【装箱数】
【套数】拆分后的【实际装柜数】
【出库时间】头程发货单【实际出库时间】
【物流商】头程发货单费用明细中的物流商
【税金文件】头程发货单费用明细中报价方式为「税金」的费用项附件，可展示多个附件
【税率(%)】对应国家在「业务配置-财务配置-VAT申报国家配置」中的当时税率
【发票编号】默认为空，通过「完善发票」维护
【发票日期】默认为空，通过「完善发票」维护
【类型】默认为空，通过「完善发票」维护，枚举「递延」「非递延」
【B00税金】默认为空，通过「完善发票」维护
【税金】默认为空，按【B00税金】×【税率(%)】自动计算
【备注】默认为空，通过「编辑备注」维护
【状态】展示当前 VAT税金申报状态
【创建时间】VAT税金申报记录创建时间
【操作】按【状态】展示「完善发票」「确认发票」「确认申报」「编辑备注」「日志」等入口

### 筛选项

【关键字类型】单选选择器，默认「运单号」，选项「运单号」「头程发货单号」「编号」「备注」
【搜索关键字】文本输入框，默认空，提示文案「请输入搜索关键字」
【物流专员】单选选择器，默认空，是否支持多选待确定
【国家】单选选择器，默认空，是否支持多选待确定
【VAT申报主体】单选选择器，默认空，是否支持多选待确定
【店铺】单选选择器，默认空，是否支持多选待确定
【日期类型】单选选择器，默认「出库时间」，选项「出库时间」「创建时间」
【日期范围】日期范围选择器，默认空，提示文案「开始日期 - 结束日期」
【是否上传税金文件】单选选择器，默认空，选项待确定

### 状态页签

| 页签 | 筛选规则 |
| --- | --- |
| 全部 | 查询全部状态数据 |
| 待完善 | 查询【状态】为「待完善」的数据 |
| 待确认 | 查询【状态】为「待确认」的数据 |
| 待申报 | 查询【状态】为「待申报」的数据 |
| 已完成 | 查询【状态】为「已完成」的数据，是否同时包含列表样例中的「已申报」待确定 |

### 页面操作

点击「重置」后清空筛选项并恢复默认值，状态页签是否恢复为默认「待完善」待确定。
点击下载图标后执行「导出列表」。
点击「导出税金文件」后按勾选数据导出税金附件压缩包。
点击列表记录的「完善发票」进入「编辑发票信息」弹窗。
点击列表记录的「确认发票」进入「确认发票」弹窗。
点击列表记录的「确认申报」进入「确认申报」二次确认弹窗。
点击列表记录的「编辑备注」进入「编辑备注」弹窗。
点击列表记录的「日志」查看操作日志；日志页面、字段和筛选规则待确定。

### 分页规则

【每页条数】默认「10条/页」，是否支持切换条数待确定
【总条数】展示当前筛选条件下的数据总数
【当前页】默认第1页，支持翻页

### 不在范围内

不提供 VAT税金申报详情页规则，原型未展开详情页。
不提供「采购员」「创建人」筛选规则，抽取文本出现但 HTML 坐标疑似隐藏，是否上线展示待确定。

### 待确定项

【编号】是系统业务编号还是列表序号待确定。
【物流专员】【国家】【VAT申报主体】【店铺】【是否上传税金文件】是否支持多选和远程搜索待确定。
状态页签默认选中「待完善」还是「全部」待确定。
列表默认排序字段和排序方向待确定。
「采购员」「创建人」是否为有效筛选项待确定。
