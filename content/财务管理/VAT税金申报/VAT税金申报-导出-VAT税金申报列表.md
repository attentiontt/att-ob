# VAT税金申报-导出-VAT税金申报列表

### 业务规则

入口：从「VAT税金申报列表」点击下载图标。

导出范围：按当前状态页签和当前筛选条件导出列表数据，是否导出全部页、当前页或勾选数据待确定。

导出文件：VAT税金申报列表导出.xlsx，实际文件名规则待确定。

### 导出字段

基础信息
【编号】列表展示的编号
【运单号】列表展示的运单号
【头程发货单号】列表展示的头程发货单号
【物流专员】列表展示的物流专员
【国家】列表展示的国家
【币种】列表展示的币种
【VAT申报主体】列表展示的 VAT申报主体
【店铺】列表展示的店铺
【箱数】列表展示的箱数
【套数】列表展示的套数
【出库时间】列表展示的出库时间
【物流商】列表展示的物流商
税金信息
【税金文件】列表展示的税金文件名称或链接，导出形式待确定
【税率(%)】列表展示的税率
【发票编号】列表展示的发票编号
【发票日期】列表展示的发票日期
【类型】列表展示的类型
【B00税金】列表展示的 B00税金
【税金】列表展示的税金
【备注】列表展示的备注
【状态】列表展示的状态
【创建时间】列表展示的创建时间

### 点击导出时校验

校验1：后端校验当前用户具备「导出列表」权限；不满足提示待确定
校验2：后端校验当前导出范围内是否存在数据；不满足提示「暂无可导出数据」
校验3：后端校验导出数据量是否超过上限；上限和超限处理待确定

### 通过校验后执行

执行1：按当前状态页签和筛选条件查询导出数据
执行2：按列表字段生成导出文件
执行3：记录导出操作日志

### 异常场景

导出数据为空：不生成文件，提示「暂无可导出数据」。
导出数据量过大：同步导出、异步导出或提示超限待确定。
重复点击：只执行一次或提示处理中，具体规则待确定。

### 不在范围内

不导出税金附件原文件；税金附件原文件通过「导出税金文件」导出。

### 待确定项

原型说明中「导出列表」写为「基于筛选项按列表导入」，是否为文案笔误待确定。
【税金文件】在 Excel 中导出文件名、链接还是附件数量待确定。
导出文件名是否包含导出日期、页签名称和操作者待确定。
