# 请款单管理-操作-打印请款单

### 业务规则

入口：从「请款单列表」或「请款单详情」点击「打印」进入「打印请款单」页面。
展示逻辑：打印页标题示例为「费用请款单」。
展示逻辑：打印页展示请款单基础信息、明细信息和签核栏。
展示逻辑：请款单明细中的应付单维度如果是入库单，则合并至同采购单作为打印明细展示；其他应付单逻辑不受影响。

基础信息
【请款单号】展示请款单号
【付款方】展示付款方
【收款对象类型】展示收款对象类型
【收款对象】展示收款对象
【账户类型】展示账户类型
【收款账户名称】展示收款账户名称
【收款账号】展示收款账号
【开户行名称】展示开户行名称
【开户行地址】展示开户行地址
【公司地址】展示公司地址
【SWIFT CODE】展示SWIFT CODE
【Routing Number】展示Routing Number
【申请人】展示申请人
【申请时间】展示申请时间
【预计付款日期】展示预计付款日期
【币种】展示币种
【申请金额】展示申请金额
【抵扣金额】展示抵扣金额
【调整金额】展示调整金额
【应付金额】展示应付金额
【应付金额大写】展示应付金额大写
【备注】展示备注

明细信息
【序号】展示明细序号
【单据编号】展示费用单、采购单、入库单、模具采购单、运单或调度单编号
【来源单号】费用单明细展示来源单号
【费用项】展示费用项
【申请金额】展示明细申请金额
【抵扣金额】展示明细抵扣金额
【调整金额】展示明细调整金额
【应付金额】展示明细应付金额

签核信息
【核准人】展示或留空供签字
【复核人】展示或留空供签字
【审批人】展示或留空供签字
【出货单位】头程或调度打印场景展示，是否所有类型展示待确定
【经手人】头程或调度打印场景展示，是否所有类型展示待确定

### 点击打印时校验

校验1：校验当前用户具备查看或打印权限；不满足提示待确定
校验2：校验请款单数据存在；不满足提示待确定

### 通过校验后执行

执行1：打开打印请款单页面
执行2：按请款单当前数据渲染基础信息和明细信息
执行3：入库单维度明细按同采购单合并展示
执行4：用户执行浏览器打印或系统打印，具体打印控件待确定

### 异常场景

应付金额大写转换失败：不允许打印或展示为空待确定
多币种请款单：是否允许同一打印单展示多币种待确定
打印后数据变更：是否需要记录打印快照待确定
