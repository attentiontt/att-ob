# 请款单管理-查询-请款单列表

### 列表数据

【请款单号】展示请款单编号
【付款方】展示公司主体
【收款对象类型】展示「供应商」「物流商」等类型
【收款对象】展示供应商编号或物流商编号
【预计付款日期】展示预计付款日期
【币种】展示币种，如「人民币(CNY)」「CNY」
【申请金额】展示请款申请金额
【抵扣金额】展示抵扣金额
【调整金额】展示成本调整金额
【应付金额】展示最终应付金额
【已付】展示已付款金额
【未付】展示未付款金额
【可退款金额】展示可退款金额，计算规则待确定
【退款中金额】展示退款中金额，计算规则待确定
【已退金额】展示已退款金额，计算规则待确定
【申请人】展示提交请款单的用户
【备注】展示请款备注
【申请时间】展示提交请款单时间
【付清时间】展示请款单付清时间
【状态】展示请款单状态
【操作】按状态展示「详情」「编辑」「删除」「废弃」「付款」「审批」「打印」「撤销」「重新申请」「退款」等入口

### 筛选项

【状态页签】页签，默认待确定，可选「全部」「已完成」「待付款」「已撤销」「待审批」「已驳回」「已废弃」
【搜索关键字】文本输入框，默认空，占位文案「请输入搜索关键字」，匹配字段待确定
【付款方】单选选择器，默认空
【申请人】单选选择器，默认空
【收款对象】文本输入框或单选选择器，默认空，控件类型待确定
【日期范围】日期范围选择器，默认空，占位文案「开始日期 - 结束日期」，对应日期字段待确定

### 查询规则

展示逻辑：进入「请款单列表」后展示分页列表，原型示例为「10条/页」「共132条」。
展示逻辑：状态页签展示数量，如「已完成(10)」「待付款(2)」「已撤销(1)」「待审批(2)」「已驳回(2)」「已废弃(1)」。
展示逻辑：列表排序规则待确定，原型未提供默认排序字段。
展示逻辑：点击「详情」进入对应类型请款单详情页。
展示逻辑：点击「打印」进入或打开「打印请款单」页面。
展示逻辑：点击「编辑」进入编辑请款单页面并预填原请款信息，除【请款单号】已生成不可改外，其他逻辑与新建请款单一致。
展示逻辑：点击「审批」打开「审批」弹窗。
展示逻辑：点击「废弃」打开「废弃请款单」确认弹窗。
展示逻辑：点击「删除」打开「删除请款单」确认弹窗。
展示逻辑：「付款」「撤销」「退款」「重新申请」在列表中出现入口，展开页面和执行规则待确定或归属其他模块。

### 状态与操作说明

| 状态 | 列表操作 | 说明 |
| --- | --- | --- |
| 所有状态 | 详情、打印 | 查看或打印请款单 |
| 已驳回 | 编辑、删除 | 编辑后可重新提交；删除为真删 |
| 待审批 | 审批 | 审批通过状态变更为「待付款」，审批不通过状态变更为「已驳回」 |
| 待付款 | 付款、废弃 | 付款规则归属财务付款；废弃后状态变更为「已废弃」 |
| 已完成 | 撤销付款、退款 | 展开规则待确定 |
| 已撤销 | 重新申请 | 展开规则待确定 |

### 不在范围内

不生成「导出」文档：原型未展开请款单列表导出入口、导出字段或执行规则。
不生成「导入付款记录」文档：原型出现导入付款记录和水单附件文案，但与财务付款模块边界待确认。
