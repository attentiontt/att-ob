# 系统-自动触发-ASIN数据拉取

### 触发条件

新增拉取清单触发：用户添加 Asin 后，系统基于用户添加的【国家/站点】+【Asin】去重结果登记数据拉取清单，新清单状态为「待拉取」。

月度定时触发：定时触发规则存在两处原型口径，待产品确认后执行。

### 取值逻辑

【国家/站点】取 Asin 所属市场分类的国家/站点
【Asin】取数据拉取清单中的 Asin
【月份】新增拉取清单触发时，市场调研页说明为每个 Asin 拉取从2020年至今的所有数据；市场分析页说明为请求时间从2020年1月到当前最新月份
【当前最新月份】市场分析页定义为每个月21号后默认最新月份为上个月，每个月21号前默认最新月份为上上月
【数据源唯一值】按【国家/站点】+【Asin】+【月份】作为唯一值，不重复写入数据
【数据更新时间】每次执行完成爬虫任务时登记
【数据最新月份】每次执行完成月度爬虫任务时登记

### 执行规则

执行1：爬虫基于数据拉取清单进行数据爬取
执行2：判断是否能在卖家精灵查询到该 Asin
执行3：不能查询到该 Asin 时，将【国家/站点】+【Asin】标记为「拉取失败」，停止后续爬虫
执行4：能查询到该 Asin 时，执行拉取命令
执行5：执行成功后，将【国家/站点】+【Asin】标记为「拉取成功」
执行6：执行中断时，将【国家/站点】+【Asin】标记为「待拉取」
执行7：每次执行完成爬虫任务时登记【数据更新时间】
执行8：每次执行完成月度爬虫任务时登记【数据最新月份】【数据更新时间】

### 异常场景

卖家精灵查询不到 Asin：标记为「拉取失败」，停止后续爬虫
爬虫任务中断：标记为「待拉取」
重复数据：按【国家/站点】+【Asin】+【月份】去重，不重复进数据

### 待确定

月度定时触发日期存在冲突：市场调研页说明为每个月26日凌晨0点5分拉取上一个月数据；市场分析页说明为每个月21日基于所有 Asin 清单统一请求数据并更新数据最新月份。
卖家精灵 API 文档链接在原型中出现，但接口字段、鉴权和错误码未展开。
