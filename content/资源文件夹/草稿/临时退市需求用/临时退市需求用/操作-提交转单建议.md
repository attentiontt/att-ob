# 操作-提交转单建议

### 业务规则

入口：从「商品退市清单」详情点击「提交转单建议」。

操作角色：计划。

尚未提交转单建议时，操作按钮展示为「提交转单建议」。提交成功后，操作按钮变更为「更新转单建议」。

点击「提交转单建议」时，打开「提交转单建议【{退市编号}】」弹窗。
点击「更新转单建议」时，打开转单建议弹窗并展示最近一次提交的数据；允许更新的清单状态待确定。

基础信息
【退市编号】展示
【MSKU】展示
【销售平台】展示
【目的国】展示
【店铺】展示
【剩余订单数】展示，取值来源待确定
建议转单明细
【建议转单数量】数值输入框，默认空，必填，只能输入正整数
【建议转单项Msku/销售平台/目的国/店铺/sku】单选选择器，默认空，必填，查询「产品管理」中状态为「启用」的 Goods ID
【备注】文本输入框，默认空，非必填，不限制字符类型，最多输入 500 个字符

建议转单明细支持点击「添加」增加一行。
【建议转单项Msku/销售平台/目的国/店铺/sku】的选项需关联一个启用的 Goods ID，并组合展示该 Goods ID 对应的 Msku、销售平台、目的国、店铺和 sku。
同一个 Goods ID 是否允许添加多行待确定。
单次可添加的明细行数上限待确定。

### 点击提交/更新时校验

校验1：首次提交时，后端校验商品退市清单状态是否允许提交转单建议；允许状态待确定，不满足时提示文案待确定。
校验2：更新时，后端校验商品退市清单状态是否允许更新转单建议；允许状态待确定，不满足时提示文案待确定。
校验3：后端校验当前用户是否有计划角色操作权限；权限模型和提示文案待确定。
校验4：【建议转单数量】必填且只能输入正整数；不满足时提示文案待确定。
校验5：【建议转单项Msku/销售平台/目的国/店铺/sku】必填，且提交时关联的 Goods ID 状态必须为「启用」；不满足时提示文案待确定。
校验6：【备注】最多输入 500 个字符；超过时不允许提交，提示文案待确定。
校验7：所有明细的【建议转单数量】合计是否不得大于【剩余订单数】待确定。

### 通过校验后执行

执行1：首次提交时，保存转单建议明细及关联的 Goods ID。
执行2：首次提交成功后，将操作按钮从「提交转单建议」变更为「更新转单建议」。
执行3：更新时，以弹窗内本次提交的明细更新转单建议；是否保留历史版本待确定。
执行4：记录操作人、操作时间和操作日志。
执行5：是否立即更新商品退市清单状态待确定；评估完成条件见[[商品退市管理/全局说明]]。

### 异常场景

选择 Goods ID 后，该 Goods ID 在提交前被停用：不允许提交，提示文案待确定。
【剩余订单数】在提交或更新前发生变化：是否阻断并要求重新填写待确定。
没有符合条件的启用 Goods ID：页面提示及是否允许提交空建议待确定。
