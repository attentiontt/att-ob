# 七、问异常场景

正常流程通常很简单，系统难点都在异常。

必须询问这些场景：

```
异常场景
├─ 订单价格与发票价格不一致
├─ 订单数量与入库数量不一致
├─ 入库后发生退货
├─ 质检不合格但先入库
├─ 供应商不认可扣款
├─ 已对账后补录入库
├─ 已对账后修改采购价格
├─ 已对账但供应商不开票
├─ 已开票但暂时不付款
├─ 已付款后发生退款
├─ 跨月调整
├─ 跨币种结算
├─ 供应商更换收款账户
├─ 同一供应商对应多个主体
├─ 预付款不足或超额抵扣
└─ 供应商倒闭或停止合作
```

每个异常都问四件事：

1. 现在怎么处理？
2. 谁处理？
3. 在哪个单据体现？
4. 最终如何影响应付和付款？
