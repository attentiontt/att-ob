

> 适用范围：产品 / 项目需求文档体系管理 层级原则：由宏观到微观，四层拆解 —— **Epic → Feature → Function Point（功能点）→ 变更记录**


## 一、目录结构规范

```
📁 产品需求文档
│
├── 📁 01_[史诗名称，如"产品开发"]/           【史诗目录】
│   ├── 史诗说明.md                          （本史诗的目标、范围、关联业务价值）
│   │
│   ├── 📁 功能模块_01_[名称，如"项目管理"]/   【功能模块目录】
│   │   ├── 功能模块说明.md                   （本模块的边界、涉及角色、整体流程图）
│   │   ├── 功能点_01_[名称].md               【功能点文件】
│   │   ├── 功能点_02_[名称].md
│   │   ├── 功能点_03_[名称].md
│   │   └── 📁 变更记录/                       【本模块专属变更记录】
│   │       ├── 变更说明_v1.0_初始版本.md
│   │       └── 变更说明_v1.x_[简述].md
│   │
│   └── 📁 功能模块_02_[名称，如"产品画像"]/
│       ├── 功能模块说明.md
│       ├── 功能点_01_[名称].md
│       └── 📁 变更记录/
│           └── 变更说明_v1.0_初始版本.md
│
├── 📁 02_[史诗名称，如"产品库"]/
│   └── ... （结构同上）
│
└── 📁 迭代/                                  【迭代管理，发布视角】
    ├── 📁 V1.10.0/
    │   ├── 0196.md
    │   ├── 0184.md
    │   └── ...（本迭代下的每一条需求编号对应一个文件）
    ├── 📁 V1.11.0/
    │   ├── ERP-10010.md
    │   └── ...
    └── 📁 V1.x.x/
```
