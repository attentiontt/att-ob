# 库存管理-查询-库存批次流水

### 列表数据

【批次号】展示本次库存批次流水关联的批次号
【来源批次号】展示调拨、换标等入库来源批次号，无来源时展示「-」
【原始批次号】展示最初形成库存的批次号，无原始批次时展示「-」
【产品名称/产品sku】展示产品名称和产品 SKU
【实体Msku】展示实体 MSKU
【仓库】展示库存发生仓库
【业务类型】展示库存批次流水业务类型
【单据编号】展示产生库存批次流水的单据编号
【实体库存可用量】展示本次实体库存可用量变更值，增加展示「+」，减少展示「-」
【实体库存可用量结余】展示本次变更后的实体库存可用量余额
【实体库存锁定量】展示本次实体库存锁定量变更值，增加展示「+」，减少展示「-」
【实体库存锁定量结余】展示本次变更后的实体库存锁定量余额
【单据备注】展示产生库存流水的单据备注
【操作人】展示产生库存流水的单据操作人
【创建时间】展示库存流水产生时刻，格式为「yyyy-mm-dd hh:m:ss」

分页
【总条数】展示符合当前筛选条件的数据总数
【当前页】展示当前页码
【总页数】展示总页数
【每页条数】默认 10 条/页

### 筛选项

【仓库】单选选择器，默认空
【搜索字段】单选选择器，默认「批次号」，可选「批次号」「来源批次号」「原始批次号」「单据编号」「产品名称」「产品sku」「实体Msku」「备注」
【搜索关键字】文本输入框，默认空，提示「请输入搜索关键字」
【业务类型】单选选择器，默认空
【时间字段】单选选择器，默认「创建时间」，可选「创建时间」
【创建时间】日期范围选择器，默认空，提示「开始日期 - 结束日期」

### 页面按钮

从「库存批次流水」点击「重置」清空筛选条件并刷新列表。
从「库存批次流水」点击顶部下载图标进入流水明细导出流程。

### 字段规则

【批次号】格式为「YYYYMMDD-仓库id-5位日序列号」
【批次号】每个仓库每产生一次入库流水时新增一个入库批次号
【来源批次号】当通过调拨或换标产生入库时，按先进先出顺序取得库存批次并写入入库单来源批次号
【仓库】取产生库存流水的单据内仓库
【产品名称/产品sku】取产生库存流水的单据明细内品名，包含物料或产品
【实体Msku】取产生库存流水的单据明细内 MSKU 信息
【业务类型】按库存批次流水业务类型规则生成
【单据编号】取产生库存流水的单据编号
【实体库存可用量】记录对实体库存可用量的变更数值，增加为「+」，减少为「-」
【实体库存可用量结余】记录本次变更后的实体库存可用量余额
【实体库存锁定量】记录对实体库存锁定量的变更数值，增加为「+」，减少为「-」
【实体库存锁定量结余】记录本次变更后的实体库存锁定量余额
【单据备注】取产生库存流水的单据备注；撤销出库单或撤销入库单不生成单据备注
【操作人】取产生库存流水的单据操作人
【创建时间】取产生库存流水的时刻，格式为「yyyy-mm-dd hh:m:ss」

### 业务类型

| 业务类型 | 实体库存可用量 | 实体库存锁定量 |
| --- | --- | --- |
| 质检入库 | + | 未展示 |
| 撤销出库 | - | 未展示 |
| 调拨入库 | + | 未展示 |
| 移库入库 | + | 未展示 |
| 其他入库 | + | 未展示 |
| 其他出库 | - | 未展示 |
| FBA出库 | - | 未展示 |
| WFS出库 | - | 未展示 |
| 调拨出库 | - | 未展示 |
| 退货出库 | - | 未展示 |
| 换标出库 | - | 未展示 |
| 换标入库 | + | 未展示 |
| 调整出库 | - | 未展示 |
| 调整入库 | + | 未展示 |
| 库存锁定 | 未展示 | + |
| 库存解锁 | 未展示 | - |

「未展示」表示原型未展示该库存字段变更方向，具体是否为空、0 或不生成流水待确认。

### 详情

原型未展示库存批次流水详情页或详情弹窗。

### 不在范围内

不支持在库存批次流水页面手工新增、编辑或删除流水。
不支持在库存批次流水页面修改批次号生成规则。
