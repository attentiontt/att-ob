# 库存管理-全局说明

### 功能范围

本模块包含「库存清单」「批次库存清单」「库存流水」「库存批次流水」「库存差异看板」。

本模块不包含调整单、入库单、出库单、销售订单、调拨单、换标单、仓库管理、供应商管理等其他模块的单据新建、编辑、审批和详情流程。

### 状态变更

原型未展示库存清单、批次库存清单、库存流水、库存批次流水、库存差异看板的单据状态流转。

库存记录按库存维度、批次维度、流水发生时间和差异数量展示。

是否需要记录「正常」「异常」「已通知」「已处理」等库存差异处理状态待确认。

### 状态与操作对照

| 记录范围 | 可执行的操作 |
| --- | --- |
| 库存清单记录 | 查询、重置、导出 |
| 批次库存清单记录 | 查询、重置、导出 |
| 库存流水记录 | 查询、重置、导出 |
| 库存批次流水记录 | 查询、重置、导出 |
| 库存差异记录 | 查询、重置、导出 |
| 差异数量不等于 0 的记录 | 系统发起钉钉通知 |

### 通用规则

【实体库存】基于仓库+库存 SKU 维度管理库存，不分销售平台，以实物的存储、盘点、出入库为核心开展库存管理
【产品库存】基于平台+仓库+库存 SKU 维度管理库存，用于区分不同销售平台在对应仓库的库存归属与流转
【仓库类型】原型展示枚举包含「自营仓」「三方仓」「FBA仓」，完整枚举待确认
【实体库存可用量】表示当前仓库、实体 MSKU 维度可售或可用库存数量
【实体库存锁定量】表示当前仓库、实体 MSKU 维度被业务单据锁定的库存数量
【产品库存可用量】表示销售平台、店铺、库存 SKU、仓库维度的可用库存数量
【产品库存锁定量】表示销售平台、店铺、库存 SKU、仓库维度被业务单据锁定的库存数量
【库存数量】允许展示正数、0 和负数；负数含义及是否允许入账待确认
【流水变更量】增加库存使用「+」展示，扣减库存使用「-」展示
【结余量】为本次流水处理后的库存余额
【创建时间】展示格式为「yyyy-mm-dd hh:m:ss」
【搜索关键字】与搜索字段选择器配合使用，默认空

### 通用查询规则

进入页面时默认展示第一页数据，原型分页示例为每页 10 条。
点击「重置」时清空当前页面筛选条件，并恢复默认分页。
用户输入筛选项后的查询触发方式待确认，原型未展示独立「查询」文字按钮。
列表为空时展示空数据状态，具体空态文案待确认。
用户无权限访问时不展示页面数据，权限点待确认。

### 通用导出规则

各页面顶部工具区展示下载图标，作为「导出」入口。
导出范围按当前页面、当前页签、当前筛选条件导出；是否支持勾选数据导出待确认。
导出文件是否追加导出时间、导出人、页签名称待确认。
导出数据量过大时是否转异步导出待确认。

### 不在范围内

不支持在本模块内新建、编辑、审批、撤回、废弃库存相关上游单据。
不支持在本模块内维护仓库、供应商、店铺、销售平台、商品、SKU、MSKU 基础资料。
不支持在本模块内处理钉钉通知接收人配置页面；仅记录库存差异通知触发规则。
