# 库存管理-系统-自动触发-库存批次流水生成

### 业务规则

当上游库存相关单据产生库存批次变更时，系统自动生成库存批次流水。

触发条件：
质检单、入库单产生入库批次变更。
调拨、移库、其他入库、其他出库、FBA 出库、WFS 出库、退货出库、换标、调整、库存锁定、库存解锁等业务产生批次库存变更。

取值逻辑：
【批次号】按「YYYYMMDD-仓库id-5位日序列号」生成；每个仓库每产生一次入库流水时新增一个入库批次号
【来源批次号】调拨或换标入库时，按先进先出顺序取得库存批次并写入来源批次号
【原始批次号】取来源链路中最初形成库存的批次号，具体传递规则待确认
【产品名称/产品sku】取产生库存流水的单据明细内品名，包含物料或产品
【实体Msku】取产生库存流水的单据明细内 MSKU 信息
【仓库】取产生库存流水的单据内仓库
【业务类型】按上游业务场景生成
【单据编号】取产生库存流水的单据编号
【实体库存可用量】按业务类型生成本次可用量变更值
【实体库存可用量结余】按本次变更后的批次可用量写入
【实体库存锁定量】按业务类型生成本次锁定量变更值
【实体库存锁定量结余】按本次变更后的批次锁定量写入
【单据备注】取产生库存流水的单据备注；撤销出库单或撤销入库单不生成单据备注
【操作人】取产生库存流水的单据操作人
【创建时间】取产生库存流水的时刻，格式为「yyyy-mm-dd hh:m:ss」

### 业务类型方向

| 业务类型 | 实体库存可用量 | 实体库存锁定量 |
| --- | --- | --- |
| 质检入库 | + | 未展示 |
| 撤销出库 | - | 未展示 |
| 调拨入库 | + | 未展示 |
| 移库入库 | + | 未展示 |
| 其他入库 | + | 未展示 |
| 其他出库 | - | 未展示 |
| FBA出库 | - | 未展示 |
| WFS出库 | - | 未展示 |
| 调拨出库 | - | 未展示 |
| 退货出库 | - | 未展示 |
| 换标出库 | - | 未展示 |
| 换标入库 | + | 未展示 |
| 调整出库 | - | 未展示 |
| 调整入库 | + | 未展示 |
| 库存锁定 | 未展示 | + |
| 库存解锁 | 未展示 | - |

「未展示」表示原型未展示该库存字段变更方向，具体是否为空、0 或不生成流水待确认。

### 异常场景

仓库为空：不生成库存批次流水，处理方式待确认。
批次库存不足：是否允许生成负库存批次流水待确认。
调拨或换标入库无可用来源批次：不生成或提示异常，处理方式待确认。
同一上游单据重复触发：同一业务明细只生成一次库存批次流水。

### 通过校验后执行

执行1：根据上游业务明细生成库存批次流水
执行2：按业务类型更新批次库存可用量和锁定量结余
执行3：关联上游单据编号
执行4：记录自动生成日志

### 不在范围内

不支持在库存批次流水生成规则内定义上游单据审批流程。
不支持在库存批次流水生成规则内维护 FIFO 批次分配参数，参数配置入口待确认。
