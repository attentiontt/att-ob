### 待确认问题

| 问题 | 影响范围 |
| --- | --- |
| 「供应商装货信息」是否只读引用「供应商管理」中的装货信息 | 影响字段来源、编辑入口和上下游引用规则 |
| 筛选条件变更后是否自动查询，或是否存在未展示的「查询」按钮 | 影响查询交互 |
| 【供应商编号】是否支持模糊查询 | 影响筛选规则 |
| 是否存在默认装货地址或默认装货联系人 | 影响采购、发货计划、头程、入库默认带出逻辑 |
| 「启用」「禁用」是否可在本模块内变更 | 影响是否需要补充操作文档 |
| 已生成采购单、发货计划、头程单、入库单是否随供应商装货信息变更同步更新 | 影响上下游联动规则 |
| 导出数据量过大时是否异步导出 | 影响导出执行规则 |
