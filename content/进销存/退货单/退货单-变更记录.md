# 退货单-变更记录

### V1.0.0

| 变更类型 | 范围 | 影响点 |
| --- | --- | --- |
| 新增 | [[退货单-全局说明]] | 定义退货单状态、退货来源、退货方式、库存批次、采购单回写和待确认范围 |
| 新增 | [[退货单-查询-退货单列表]] | 定义列表字段、明细字段、筛选项和列表操作入口 |
| 新增 | [[退货单-查询-退货单详情]] | 定义详情基础信息、明细信息和关联单据待确认范围 |
| 新增 | [[退货单-操作-新建编辑退货单]] | 根据「新建/编辑退货单（暂时不做）」页面记录新建、编辑字段和校验 |
| 新增 | [[退货单-操作-添加退货产品]] | 定义添加退货产品弹窗、查询、选择和添加规则 |
| 新增 | [[退货单-操作-审批退货单]] | 定义待审批状态下审批通过、审批驳回规则 |
| 新增 | [[退货单-操作-删除退货单]] | 定义待审批状态下删除确认和删除规则 |
| 新增 | [[退货单-操作-撤销退货退款单]] | 记录原型已出现但入口未确认的撤销弹窗规则 |
| 新增 | [[退货单-系统-自动触发-审批通过回写采购单与库存]] | 定义审批通过后采购单回写、库存和入库单待确认规则 |
| 新增 | [[退货单-导出-退货单列表]] | 定义列表导出范围、字段、校验和执行 |

### 待确认问题

| 问题 | 来源 | 说明 |
| --- | --- | --- |
| 新建/编辑是否本期开发 | 新建/编辑页面文件名 | 源文件名包含「暂时不做」 |
| 退货单号字段命名 | 列表、详情、备注、导出 | 原型出现「退款单号」「退货退款单号」「退货换货单号」「退货单号」 |
| 退货量可退口径 | 列表备注、新建/编辑字段说明 | 原型存在「到货数量 - 已退货数量」和「采购量 - 待到货量」两种口径 |
| 备注字数限制 | 列表备注、新建/编辑字段说明 | 原型存在100字符和500字符两种限制 |
| 库存影响 | 新建/编辑与自动触发说明 | 原型明确使用库存校验，但未明确审批通过后库存扣减方式 |
| 入库单影响 | 导出字段与添加产品规则 | 原型出现入库单号、入库时间和入库批次，但未明确回写入库单规则 |
| 撤销入口和回滚 | 列表弹窗 | 原型有撤销弹窗，但状态操作表未列出撤销 |
