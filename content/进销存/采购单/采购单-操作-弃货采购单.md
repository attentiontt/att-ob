# 采购单-操作-弃货采购单

### 业务规则

入口：从「采购单列表」待到货数据点击「弃货」。

展示逻辑：点击后弹出确认框，文案为「弃货部分的产品将无法入库，你还要继续吗？」；继续后展示剩余订单量大于 0 的采购单明细，用户录入本次弃货量。

基础信息
【采购单号】展示待弃货采购单编号
【状态】弃货前状态为「待到货」
明细信息
【图片】展示采购产品图片
【产品名称/SKU】展示采购产品名称和 SKU
【店铺】展示采购产品店铺
【MSKU】展示采购产品 MSKU
【采购量】展示明细采购数量
【入库量】展示明细已入库数量
【待质检量】展示明细待质检数量
【待转单量】展示明细待转单数量
【剩余订单量】展示明细剩余订单数量
【弃货量】数值输入框，默认 0，允许输入 0 到【剩余订单量】范围内的数值

### 点击提交/确定时校验

校验1：前端校验【弃货量】是否在 0 到【剩余订单量】范围内；不满足提示待确认
校验2：后端校验采购单状态是否为「待到货」；不满足提示「单据状态为{状态}，无法操作」
校验3：后端校验当前用户是否有弃货权限；不满足提示「无权限操作」
校验4：后端校验弃货数是否大于剩余到货数；大于时提示「弃货数无法大于剩余到货数，请刷新页面重试」
校验5：后端校验【弃货金额】是否大于采购单剩余未申请金额；大于时提示「采购单剩余未申请金额不足，无法结束到货」

### 通过校验后执行

执行1：按用户填写的【弃货量】，将对应采购单明细的剩余订单数量转为弃货数量
执行2：更新采购单明细【弃货量】【剩余订单量】【弃货金额】
执行3：当单个明细【待质检量】【剩余订单量】【待转单量】全部为 0 时，将该明细状态标记为已完成
执行4：当采购单全部明细均为已完成时，将采购单状态变更为「已完成」
执行5：记录操作日志

### 异常场景

弃货数大于剩余到货数：不允许结束到货，提示「弃货数无法大于剩余到货数，请刷新页面重试」
弃货金额大于剩余未申请金额：不允许结束到货，提示「采购单剩余未申请金额不足，无法结束到货」
全部【弃货量】为 0：是否允许提交待确认

### 不在范围内

不展开弃货后财务请款、库存和入库模块处理规则
