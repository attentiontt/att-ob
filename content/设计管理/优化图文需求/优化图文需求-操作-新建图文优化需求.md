# 优化图文需求-操作-新建图文优化需求

### 业务规则

入口：从「优化图文需求」列表点击「新建优化需求」。
展示逻辑：打开「新建图文优化需求」弹窗。
展示逻辑：弹窗展示「保存」「提交」「取消」按钮。
展示逻辑：点击「添加」商品前必须先选择【销售平台】。

基础信息
【优化需求名称】文本输入框，默认空，必填，不限制字符类型，最多输入100个字符
【销售平台】单选选择器，默认空，必填，数据来源销售平台 name
【需求对接人】单选选择器，默认当前登录用户，当登录用户角色为「运营员」或「运营主管」时自动预填为自己，选项为角色为运营员/运营主管的启用用户
【需求附件】附件上传，默认空，非必填，不限制附件类型，最多上传3个附件，单个文件最多20MB
【文件路径】文本输入框，默认空，必填，不限制字符类型，最多输入500个字符
【备注】文本输入框，默认空，非必填，不限制字符类型，最多输入1000个字符
【期望交付时间】日期选择器，默认空，必填
预估工序
【策划方案数】数值输入框，默认0或空，必填，只能输入0或正整数，支持切换「整套」或「优化」
【视频脚本制作数】数值输入框，默认0或空，必填，只能输入0或正整数
【白底拍摄数】数值输入框，默认0或空，必填，只能输入0或正整数
【场景拍摄数】数值输入框，默认0或空，必填，只能输入0或正整数
【视频数】数值输入框，默认0或空，必填，只能输入0或正整数，支持切换「新视频」或「优化视频」
【白底数】数值输入框，默认0或空，必填，只能输入0或正整数
【场景数】数值输入框，默认0或空，必填，只能输入0或正整数
【主图数】数值输入框，默认0或空，必填，只能输入0或正整数
【A+数】数值输入框，默认0或空，必填，只能输入0或正整数
【海报数】数值输入框，默认0或空，必填，只能输入0或正整数
【视频剪辑数】数值输入框，默认0或空，必填，只能输入0或正整数
商品清单
【序号】从1开始，升序自增1
【Msku】展示商品 MSKU
【产品名称】展示产品名称
【Sku】展示 SKU
【Item ID】展示 Item ID
【产品分类】展示产品分类
【店铺】展示店铺
【销售国】展示销售国
【操作】展示「移除」

### 点击保存时校验

校验1：前端校验必填字段不能为空；不满足提示待确定。
校验2：前端校验需求数量类字段只能输入0或正整数；不满足提示待确定。
校验3：前端校验商品清单至少一条；不满足提示待确定。
校验4：后端校验当前用户具备新建权限；不满足提示待确定。

### 点击提交时校验

校验1：沿用点击保存时校验。
校验2：后端校验当前优化图文需求可提交；不满足提示待确定。

### 通过校验后执行

执行1：点击「保存」时创建优化图文需求，状态为「待提交」，是否一定为「待提交」待确定。
执行2：点击「提交」时创建优化图文需求，状态为「待排期」。
执行3：保存基础信息、预估工序、商品清单、附件、文件路径和备注。
执行4：刷新「优化图文需求」列表。
执行5：记录操作日志。

### 异常场景

未选择【销售平台】点击「添加」商品：提示「请选择销售平台」。
选择商品后修改【销售平台】：清空已选商品清单数据。
附件上传失败：不允许保存或允许保存待确定。
重复点击「保存」或「提交」：只执行一次或提示处理中，具体规则待确定。

### 不在范围内

不展开商品选择弹窗的查询和分页规则。
