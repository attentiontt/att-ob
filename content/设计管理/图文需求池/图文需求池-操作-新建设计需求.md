# 图文需求池-操作-新建设计需求

### 业务规则

入口：从「图文需求池」列表勾选数据后点击「新建设计需求」，或从「更多」菜单点击「新建设计需求」。
展示逻辑：打开「新建设计需求」弹窗。
展示逻辑：系统将选中图文需求池数据填充至「商品清单」，其他信息由用户自行填写。
展示逻辑：创建成功后同时关联图文需求池数据与新设计需求。

基础信息
【设计需求编号】自动生成，格式为 SJ + yymmdd + 三位天序列号，序列号跨日清零，从1开始，例如「SJ240101001」「SJ240102001」
【设计需求名】文本输入框，默认取父商品名称，必填，最多输入100个字符，任务排期后不允许修改
【父产品前台链接】文本输入框，默认取商品清单中任意一条有 Item ID 的数据转化为链接，非必填，最多输入500个字符
【文件路径】文本输入框，默认空，非必填
【需求类型】单选选择器，默认按图文需求池【需求类型】取值，可选「新品」「优化」
【设计需求类型】单选选择器，默认空，数据来源字典管理，是否必填待确定
【期望交付时间】日期选择器，默认空，非必填或必填待确定
【附件】附件上传，默认空，支持扩展名「.rar」「.zip」「.doc」「.docx」「.pdf」「.jpg」等，最多上传文件数待确定，单个文件最大20MB
商品清单
【Msku】展示并保存选中图文需求池对应 MSKU
【产品名称】展示产品名称
【Sku】展示 SKU
【Item ID】展示 Item ID
【平台】展示销售平台
【店铺】展示店铺
【目的国】展示销售国

### 点击提交/确定时校验

校验1：前端校验至少选择一条图文需求池数据；不满足提示待确定。
校验2：前端校验选中数据均已有【排期批次】；无排期批次时提示「请选择排期批次的数据」。
校验3：前端校验选中数据是否已关联设计需求；已关联时提示「存在{Msku/销售平台/店铺/销售国}已关联设计需求，请取消勾选后重试」。
校验4：前端校验「新建设计需求」弹窗必填字段不能为空；不满足提示待确定。
校验5：后端校验当前用户具备新建设计需求和关联权限；不满足提示待确定。

### 通过校验后执行

执行1：创建设计需求主表和商品清单。
执行2：将新设计需求与选中图文需求池数据建立关联。
执行3：如果存在缓存导致数据实际已关联设计需求，则不覆盖原有关联数据，保持不动。
执行4：刷新「图文需求池」列表。
执行5：记录操作日志。

### 异常场景

存在无排期批次数据：不允许创建关联，提示「请选择排期批次的数据」。
存在已关联设计需求数据：不允许创建关联，提示原型指定文案。
附件上传失败：不允许提交或允许保存待确定。
重复点击：只执行一次或提示处理中，具体规则待确定。

### 不在范围内

不展开设计需求任务信息、模板另存为、新增任务、删除任务的完整规则。

### 待确定项

【期望交付时间】是否必填待确定。
【设计需求类型】枚举和必填规则待确定。
新建设计需求成功后图文需求池状态是否立即变为「待开始」或保持「已排期」待确定。
