# 图文需求池-系统-自动触发-生成图文设计需求

### 业务规则

当用户从「图文需求池」执行「按父商品自动创建」或相关新建设计需求操作后，系统按规则生成「设计需求」并关联图文需求池。

触发条件：
用户确认「按父商品自动创建」
选中数据已转化为销售国维度
选中数据【排期状态】为「已排期」

取值逻辑：
【设计需求编号】自动生成，格式为 SJ + yymmdd + 三位天序列号，序列号跨日清零，从1开始，例如「SJ240101001」
【设计需求名称】取【父商品名称】
【父产品前台链接】取商品清单中任意一条有 Item ID 的数据，转化为链接存入
【文件路径】默认空
【需求类型】当图文需求池【需求类型】为「新品」时取「新品」，当图文需求池【需求类型】为「变更」时取「优化」
【设计需求类型】默认空，字段来源字典管理，是否自动取值待确定
【期望交付时间】默认空
【附件】默认空
【商品清单】取分组内销售国维度商品数据

### 异常场景

商品清单为空：不生成设计需求，提示文案待确定。
同组内存在已关联设计需求数据：是否跳过或阻断待确定。
字段取值缺失：允许为空或阻断待确定。

### 通过校验后执行

执行1：按分组生成设计需求主表。
执行2：生成设计需求商品清单。
执行3：建立图文需求池与设计需求关联关系。
执行4：刷新「图文需求池」列表。
执行5：记录系统生成日志。
