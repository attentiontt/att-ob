# 设计需求管理-操作-导入更新设计需求

### 业务规则

入口：从「设计需求管理-需求视图」点击「导入更新设计需求」打开「导入」弹窗。
展示逻辑：导出模板时，系统导出所有「待排期」数据并填充到导入模板表格。
展示逻辑：导入更新模板相较导入新增模板增加【设计需求编号】。
展示逻辑：导入成功后刷新并覆盖设计任务和字段。

导入文件
【文件】附件上传，默认空，必填，仅支持 xlsx
【导入结果】展示导入后结果，格式为「总共导入xxx条数据，导入成功 xxx 条，导入失败 xxx 条」
模板字段
【设计需求编号】文本，必填，必须存在且状态为「待排期」
【设计需求名称】文本，非必填或必填待确定，最多100位
【父产品前台链接】文本，非必填，最多500位
【文件路径】文本，非必填，最多500位
【需求类型】枚举，必填，只能填写「新品」或「优化」
【设计需求类型】枚举，必填，必须为字典管理中的值
【期望交付时间】日期，非必填，格式为 yyyy-mm-dd 或 yyyy/mm/dd
【A+图片张数】数值或文本，非必填，最多20位
【主图图片张数】数值或文本，非必填，最多20位
【其他图片张数】数值或文本，非必填，最多20位
【需求分级】枚举，非必填，必须为字典信息
【需求备注】文本，非必填，最多500位
【销售国ID】文本，非必填，支持多个销售国 ID 用逗号分隔
【国家】导出模板预填，取商品清单里面所有国家，多个用逗号分隔
【父商品编号】导出模板预填，取商品清单里面所有父商品编号，多个用逗号分隔
【父商品名称】导出模板预填，取商品清单里面所有父商品名称，多个用逗号分隔
【商品数量】导出模板预填，取商品清单数量汇总
【商品清单】导出模板预填，格式为「msku 产品名称」
【创建日期】导出模板预填，取设计需求创建日期
【出库日期】导出模板预填，取商品清单中最早预计出库时间，如有实际出库时间则取实际出库时间
【预计开售时间】导出模板预填，取商品清单中最早预计开售时间，如有实际开售时间则取实际开售时间
【运营】导出模板预填，取商品清单中的运营，多个用逗号分隔
【是否拿样】填写「是」时校验拿样负责人和预计开始、结束时间
【是否文案策划】填写「是」时校验文案策划负责人和预计开始、结束时间
【是否需求确认】填写「是」时校验需求确认负责人和预计开始、结束时间
【是否摄影准备】填写「是」时校验摄影准备负责人和预计开始、结束时间
【是否摄影】填写「是」时校验摄影负责人和预计开始、结束时间
【是否渲染】填写「是」时校验渲染负责人和预计开始、结束时间
【是否设计】填写「是」时校验设计负责人和预计开始、结束时间
【拿样-负责人】默认按业务配置-设计分类分工配置预填摄影助理，多个用逗号分隔，导入时校验是否为对应角色内的启用用户
【文案策划-负责人】默认按业务配置-设计分类分工配置预填策划文案，多个用逗号分隔
【需求确认-负责人】默认按业务配置-设计分类分工配置预填设计师，多个用逗号分隔
【摄影准备-负责人】默认按业务配置-设计分类分工配置预填摄影助理，多个用逗号分隔
【摄影-负责人】默认按业务配置-设计分类分工配置预填摄影师，多个用逗号分隔
【渲染-负责人】默认按业务配置-设计分类分工配置预填渲染，多个用逗号分隔
【设计-负责人】默认按业务配置-设计分类分工配置预填设计师，多个用逗号分隔
【各任务预计开始时间】日期，填写对应负责人时校验格式为 yyyy-mm-dd 或 yyyy/mm/dd
【各任务预计结束时间】日期，填写对应负责人时校验格式为 yyyy-mm-dd 或 yyyy/mm/dd

### 点击导入时校验

校验1：校验【设计需求编号】是否存在；不满足提示「设计需求编号不存在」
校验2：校验【设计需求编号】对应状态是否为「待排期」；不满足提示「设计需求编号为未排期」
校验3：校验【设计需求名称】字符数是否超过100位；不满足提示「第x行设计需求名称字符数最多100」
校验4：校验【父产品前台链接】字符数是否超过500位；不满足提示「第x行父产品前台链接字符数最多500位」
校验5：校验【文件路径】字符数是否超过500位；不满足提示「第x行文件路径字符数最多500位」
校验6：校验【需求类型】是否为「新品」或「优化」；不满足提示「第x行需求类型只能是新品或优化」
校验7：校验【设计需求类型】是否为字典管理中的值；不满足提示「第x行设计需求类型的值不存在」
校验8：校验【期望交付时间】格式是否为 yyyy-mm-dd 或 yyyy/mm/dd；不满足提示「第x行期望交付时间的日期格式不正确」
校验9：校验图片张数字段字符数是否超过20位；不满足提示「第x行文字符数最多20位」
校验10：校验【需求分级】是否为字典信息；不满足提示「第x行需求分级填写不正确」
校验11：填写「是」的任务类型必须有对应负责人、预计开始时间和预计结束时间；不满足提示待确定
校验12：每条需求至少存在一组任务类型；不满足提示「XX行至少需要有一个任务」

### 通过校验后执行

执行1：按【设计需求编号】定位待更新设计需求。
执行2：更新设计需求基础字段和任务排期字段。
执行3：刷新覆盖设计任务和字段，旧任务的保留或废弃逻辑待确定。
执行4：导入成功后刷新设计需求列表。
执行5：展示导入结果，失败行不更新数据。
执行6：记录操作日志。

### 异常场景

设计需求状态不是「待排期」：不允许导入更新该行。
部分成功部分失败：成功行更新，失败行仅提示；是否支持失败明细下载待确定。
模板预填字段被修改：是否参与导入更新待确定。
重复点击「导入」：只执行一次或提示处理中，具体规则待确定。

### 不在范围内

不定义业务配置-设计分类分工配置的维护规则。
不定义导入模板下载文件名和模板样式。
