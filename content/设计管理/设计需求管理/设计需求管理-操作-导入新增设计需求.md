# 设计需求管理-操作-导入新增设计需求

### 业务规则

入口：从「设计需求管理-需求视图」点击「导入新增设计需求」打开「导入」弹窗。
展示逻辑：支持导入格式为 xlsx 的文件，手动修改文件后缀无效。
展示逻辑：模板表头不可更改，不可删除。
展示逻辑：数据记录不超过 xxx 条，具体上限待确定。
展示逻辑：弹窗提供「下载导入模板」「选择文件」和导入结果展示。

导入文件
【文件】附件上传，默认空，必填，仅支持 xlsx
【导入结果】展示导入后结果，格式为「总共导入xxx条数据，导入成功 xxx 条，导入失败 xxx 条」
模板字段
【设计需求名称】文本，必填，最多100位
【父产品前台链接】文本，非必填，最多500位
【文件路径】文本，非必填，最多500位
【需求类型】枚举，必填，只能填写「新品」或「优化」
【设计需求类型】枚举，必填，必须为字典管理中的值
【期望交付时间】日期，非必填，格式为 yyyy-mm-dd 或 yyyy/mm/dd
【A+图片张数】数值或文本，非必填，最多20位
【主图图片张数】数值或文本，非必填，最多20位
【其他图片张数】数值或文本，非必填，最多20位
【需求分级】枚举，非必填，必须为字典信息
【需求备注】文本，非必填，最多500位
【销售国ID】文本，非必填，支持多个销售国 ID 用逗号分隔
【Msku】文本，必填，支持多个 MSKU 换行输入
【拿样-负责人】文本，非必填，基于任务类型校验是否为对应角色内的启用用户
【拿样-预计开始时间】日期，非必填，填写负责人时校验格式为 yyyy-mm-dd 或 yyyy/mm/dd
【拿样-预计结束时间】日期，非必填，填写负责人时校验格式为 yyyy-mm-dd 或 yyyy/mm/dd
【文案策划-负责人】文本，非必填，校验规则同【拿样-负责人】
【文案策划-预计开始时间】日期，非必填，校验规则同【拿样-预计开始时间】
【文案策划-预计结束时间】日期，非必填，校验规则同【拿样-预计结束时间】
【需求确认-负责人】文本，非必填，校验规则同【拿样-负责人】
【需求确认-预计开始时间】日期，非必填，校验规则同【拿样-预计开始时间】
【需求确认-预计结束时间】日期，非必填，校验规则同【拿样-预计结束时间】
【摄影-负责人】文本，非必填，校验规则同【拿样-负责人】
【摄影-预计开始时间】日期，非必填，校验规则同【拿样-预计开始时间】
【摄影-预计结束时间】日期，非必填，校验规则同【拿样-预计结束时间】
【渲染-负责人】文本，非必填，校验规则同【拿样-负责人】
【渲染-预计开始时间】日期，非必填，校验规则同【拿样-预计开始时间】
【渲染-预计结束时间】日期，非必填，校验规则同【拿样-预计结束时间】
【设计-负责人】文本，非必填，校验规则同【拿样-负责人】
【设计-预计开始时间】日期，非必填，校验规则同【拿样-预计开始时间】
【设计-预计结束时间】日期，非必填，校验规则同【拿样-预计结束时间】

### 点击导入时校验

校验1：前端校验文件格式是否为 xlsx；不满足提示待确定
校验2：前端校验模板表头不可更改、不可删除；不满足提示待确定
校验3：前端校验导入记录数不超过上限；不满足提示待确定
校验4：校验【设计需求名称】字符数是否超过100位；不满足提示「第x行设计需求名称字符数最多100位」
校验5：校验【父产品前台链接】字符数是否超过500位；不满足提示「第x行父产品前台链接字符数最多500位」
校验6：校验【文件路径】字符数是否超过500位；不满足提示「第x行文件路径字符数最多500位」
校验7：校验【需求类型】是否为「新品」或「优化」；不满足提示「第x行需求类型只能是新品或优化」
校验8：校验【设计需求类型】是否为字典管理中的值；不满足提示「第x行设计需求类型的值不存在」
校验9：校验【期望交付时间】格式是否为 yyyy-mm-dd 或 yyyy/mm/dd；不满足提示「第x行期望交付时间的日期格式不正确」
校验10：校验图片张数字段字符数是否超过20位；不满足提示「第x行文字符数最多20位」
校验11：校验【需求分级】是否为字典信息；不满足提示「第x行需求分级填写不正确」
校验12：校验【需求备注】字符数是否超过500位；不满足提示「第x行文字符数最多500位」
校验13：校验每条需求至少存在一组任务类型；不满足提示「XX行至少需要有一个任务」
校验14：填写负责人时，校验负责人是否为对应任务类型角色内的启用用户；不满足提示待确定
校验15：填写负责人时，校验对应预计开始时间和预计结束时间格式；不满足提示「第x行预计开始时间的日期格式不正确」或待确定

### 通过校验后执行

执行1：按导入数据新增设计需求，生成【设计需求编号】。
执行2：生成或关联商品清单，商品清单取值逻辑待确定。
执行3：按填写的任务组生成任务排期信息。
执行4：导入成功后刷新设计需求列表。
执行5：展示导入结果，失败行不生成数据。
执行6：记录操作日志。

### 异常场景

部分成功部分失败：成功部分生成设计需求，失败部分仅提示，是否支持下载失败明细待确定。
MSKU 不存在：处理规则待确定。
销售国 ID 不存在：处理规则待确定。
重复导入相同设计需求名称：是否允许待确定。
重复点击「导入」：只执行一次或提示处理中，具体规则待确定。

### 不在范围内

不定义导入模板下载文件名和模板样式。
不定义失败明细下载格式，原型未展开。
