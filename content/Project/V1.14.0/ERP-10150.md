### 2.头程发货单新增操作日志

#### 需求范围

| 系统 | 页面 | 本次需求 |
| --- | --- | --- |
| ERP | 头程发货单 | 接入统一操作日志入口、查询及展示 |
| ERP | 头程物流跟踪 | 接入统一操作日志入口、查询及展示 |
| SRM | 头程发货单 | 接入统一操作日志入口、查询及展示 |
| SRM | 头程物流跟踪 | 接入统一操作日志入口、查询及展示 |

操作日志入口与展示

### 4.1 入口

- ERP、SRM 的「头程发货单」列表，在单据操作区增加「操作日志」入口。
- ERP、SRM 的「头程物流跟踪」列表，在单据操作区增加「操作日志」入口。
- 如页面已有「更多」菜单，则入口放入「更多」菜单；如统一操作日志规范已有固定位置，则以统一规范的位置为准。
- 入口不受单据状态限制，用户拥有当前页面查看权限即可查看操作日志。
- 点击「操作日志」后，打开系统统一操作日志弹窗/页面，不跳转到新的业务单据。
![[Pasted image 20260720173801.png]]
### 4.2 查询逻辑

- 头程发货单：【发货单号】作为业务编号。
- 头程物流跟踪：【发货单号】作为业务编号。
- 默认按【操作时间】倒序展示，最新日志在最前。

###  头程发货单触发项

以下操作成功后生成操作日志：

| 操作点/操作类型      | 操作内容要求                                 |
| ------------- | -------------------------------------- |
| 分配 OA 信息      | 记录【是否OA】原值与新值；如引起状态回退或费用数据清空，同时记录联动结果  |
| 分配物流人员        | 记录物流人员原值与新值                            |
| 分配物流商         | 记录费用项及物流商原值与新值                         |
| 录入计提费用        | 记录发生变化的费用项、计提金额和计提增值税                  |
| 维护/确认订舱       | 记录发生变化的订舱字段；确认订舱时记录状态/字段变化             |
| 维护/确认提货       | 记录发生变化的提货字段；确认提货时记录头程发货单状态/字段变化及实际出库时间 |
| 维护资料信息        | 记录发生变化的资料状态和附件操作                       |
| 生成/更新/合并生成报关单 | 记录操作类型及生成、更新的报关单编号                     |
| 录入物流日志        | 记录日志类型、发生日期；备注按统一日志脱敏与长度规则处理           |
| 编辑计量体积/重量     | 记录字段原值与新值                              |
| 拦截            | 记录拦截前后目的仓及拦截原因，沿用现有格式                  |
| 编辑物流备注        | 记录物流备注原值与新值                            |
| 录入实际费用        | 记录发生变化的费用项、实际金额和实际增值税                  |
| 费用核对/驳回       | 记录费用项、核对结果或驳回结果                        |
| 调柜单重新确认联动更新   | 记录为系统自动操作，并记录触发来源和被更新字段                |

###  头程物流跟踪触发项

以下操作成功后生成操作日志：

| 操作点/操作类型    | 操作内容要求                               |
| ----------- | ------------------------------------ |
| 录入物流轨迹      | 记录发生变化的物流节点、预计/实际时间原值与新值，以及由此产生的状态变化 |
| 确认上架/批量确认上架 | 记录实际上架时间及状态变化；批量操作按头程物流跟踪单逐条记录       |
