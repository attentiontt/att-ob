#### 第一步：
先判断 信息维护ID + 起运国 是否为全球补货产品
判断依据：检查「全球补货配置」中是否存在该 Item ID为启用 的多起运国配置数据。
若是：【计算方式 2（多起运国场景）】；若否：【计算方式 1（单起运国场景）】；

##### 计算方式1
第二步：
获取补货日历的预计计算日期、补货周期、审批天数、理论交期计算出 「发货日期」；

第三步：
获取补货规则中配置的头程时效，和第二步的发货日期，计算出「 预计到货日期」；

第四步：
获取补货规则中配置的安全库存天数，和第三步的预计到货日期，计算出 「计算卖到日期」；

第五步：
获取智能补货面板中的预测消耗面板数据，逐日推演库存结余。
根据 当日库存结余 = 期初在库 - 当日预测销量 + 当日到货数量（在途/待发） + 实际补货量 - 库存去噪；

第六步：
根据第五步的结果，结合第三步和第四步的 预计到货日期 ~ 计算卖到日期，获取对应区间段内的「库存信息」；

第七步：
系统判断与缺口统计
若「预计到货日期 ≤ 日期 < 计算卖到日期」且「当日库存结余 < 0」：统计为常规缺货日，天数计入「补货天数」，缺口绝对值计入「补货数量」。
若「日期 < 预计到货日期」且「当日库存结余 < 0」：统计为紧急缺货，缺口绝对值计入「紧急补货数量」


##### 计算方式2
第二步：
获取补货日历的预计计算日期、补货周期、审批天数、理论交期计算出 「发货日期」；

第三步：
获取全球补货规则中配置的头程时效，和第二步的发货日期，计算出各自 「预计到货日期」；

第四步：
获取全球补货规则中配置的安全库存天数，和第三步的 预计到货日期，计算出各自 「计算卖到日期」；

第五步：
通过全球补货规则中配置的默认国，取默认国的 预计到货日期、计算卖到日期 作为后续计算；

第六步：
获取智能补货面板中的预测消耗面板数据，逐日推演库存结余。
根据 当日库存结余 = 期初在库 - 当日预测销量 + 当日到货数量（在途/待发） + 实际补货量 - 库存去噪；

第七步：
根据第六步的结果，结合第四步和第五步的 预计到货日期 ~ 计算卖到日期，获取对应区间段内的「库存信息」；

第八步：
系统判断与缺口统计
若「预计到货日期 ≤ 日期 < 计算卖到日期」且「当日库存结余 < 0」：统计为常规缺货日，天数计入「补货天数」，缺口绝对值计入「补货数量」。
若「日期 < 预计到货日期」且「当日库存结余 < 0」：统计为紧急缺货，缺口绝对值计入「紧急补货数量」

第九步：
获取全球补货规则中的产能信息和产能使用率，计算得出 每个起运国在补货周期内的产能数据（补货周期产能）
单个起运国补货周期产能 = 该起运国日产能 × 产能使用率 × 补货周期天数

第十步：
按优先级分配补货缺口到各起运国
如果按照产能比例也需要按照优先级计算
1.按起运国优先级从高到低排序；
2.对优先级最高的起运国，分配其「补货周期产能」上限的补货量，从总补货缺口里扣减已分配的数量；
 若 剩余缺口数量 < 补货周期内的产能上限，则两者取小。
3.若扣减后仍有剩余缺口，则分配给下一级优先级的起运国，重复步骤 2；
4.若所有起运国的产能分配完仍有缺口，记录缺口数据
5.缺口数据则由「默认国」兜底承接。

按产能比例分配需求量到各起运国 
1.计算各国的产能比例
  单国产能 / 多国产能汇总
  循环计算所有起运国
2.产能比例 * 总需求量  = 单国的需求量
  按照优先级计算起运国需求量，优先级最低的起运国用减法
