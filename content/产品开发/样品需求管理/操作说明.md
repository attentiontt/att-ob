### 打样

弹窗展示填写字段：
【样品需求套数】数值输入框；只能输入正整数
【供应商/链接】文本输入框；不限制字符类型，最多200位字符
【打样时间】单选日期选择器，默认选中今天；不能选择未来的时间
【打样备注】文本输入框；不限制字符类型，最多500位字符


在点击确定时
执行1:生成打样明细
【样品需求套数】填写内容
【供应商/链接】填写内容
【打样备注】填写内容
【打样时间】填写内容
【打样序号】按照当前明细数，第一条为1，第二条为2，以此类推
【打样编号】等于样品需求编号拼接打样序号


### 到样
弹窗展示填写字段：
【样品到样套数】数值输入框；只能输入正整数；默认预填样品需求套数
【送样方式】
【到样备注】文本输入框；不限制字符类型，最多500位字符

非填写字段
【到样时间】操作到样点击确认的时间

在点击确定时执行校验
校验1：打样明细状态是否满足为待到样
	不满足：提示打样明细状态为{状态}，无法到样
	满足：则通过校验，进入执行

满足校验后执行
执行1：按照填写内容填充打样明细
执行2：按照样品类型
	T1
		执行1：将打样明细的状态变更为初样确认
	非T1
		执行1：将打样明细的状态变更为待评估
		执行2：按打样明细生成样品评估报告




### 初样确认
【初样确认结果】单选框；选项：通过、不通过
【初样备注】文本输入框；不限制字符类型，字符限制500位字符，初样确认结果不通过时必填

在点击确定后执行校验
校验1：打样明细状态是否满足为待初样确认
否：提示打样明细状态为{状态}，无法初样确认

通过校验后
执行1：将打样明细的状态变更为“待评估”
执行2：按打样明细生成样品评估报告

### 签样

| 字段   | 是否必填 | 控件类型  | 说明                                                   |
| ---- | ---- | ----- | ---------------------------------------------------- |
| 签样时间 | 是    | 日期选择器 | 单选日期选择器/时间，默认预填当前，可以修改                               |
| 签样图片 | 是    | 图片上传  | · 支持JPG，PNG，BMP格式  <br>· 每张图片大小不可超过 5M  <br>· 最多上传9张 |
| 签样备注 | 否    | 文本框   | 不限制字符类型，字符限制500位字符（在列表处鼠标移入可以展示编辑icon，可以改）           |
