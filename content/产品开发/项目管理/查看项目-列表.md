

### 查看项目列表

| 字段     | 说明                                                                                                                                                                                          |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| -      | 默认按照创建时间倒序                                                                                                                                                                                  |
| 预计开发时间 | 新建项目时填写                                                                                                                                                                                     |
| 实际开发时间 | 实际启动的时间                                                                                                                                                                                     |
| 预计出库时间 | 项目进度里面的预计出库时间，更新                                                                                                                                                                            |
| 实际出库时间 | 项目进度里面的实际出库时间                                                                                                                                                                               |
| 预计投入时间 | 按【预计开始时间(初始)】的最后一个节点的结束时间减去第一个节点的开始时间                                                                                                                                                       |
| 实际投入时间 | 状态为待启动：  <br>空值  <br>  <br>状态为进行中/已完成：  <br>=当前时间-实际开始时间，直到项目流转到出库最终结束后，通过出库的实际结束时间-实际开始时间，停止变更  <br>  <br>状态为已废弃：  <br>空值                                                                  |
| 预计上架时间 | 预计上架时间更新逻辑：  <br>实际出货日期为空时：  <br>当前时间<"出货日期"的预计结束时间-更新时间，取预计结束时间-更新时间+物流时效  <br>当前时间>"出货日期"的预计结束时间-更新时间，取当前时间+物流时效  <br>实际出货日期有值时，则取实际出货日期时间<br><br>物流时效见下方解释                               |
| 实际上架时间 | 当项目里面所有goods id的头程物流跟踪的状态变成已完成                                                                                                                                                              |
| 实际上架时间 | 在确认上架时触发，头程物流跟踪对应的发货单的商品明细，检测到商品明细的msku的节点=待上架，则将msku的节点变更为已上架，记录msku的实际上架时间为头程物流跟踪的实际上架时间<br><br>查出所有进行中的项目，并且项目的当前节点等于出货日期，若满足项目所有msku的节点均>=已上架（已销售国的维度），则记录对应项目的实际上架时间等于项目里面最晚的msku的上架时间 |
| 物流时效   | 从业务配置中取值，取头程时效配置起运地中国至项目的"目的国"的运输方式为整柜海卡或散货海卡的时效，多个目的国多个时效则取最短的时效，如果取不到则取参数值{海运时效}                                                                                                          |
| 项目节点   | 项目进度里面最新的主线节点，只有进行中的时候有值，待启动、已完成、已废弃均为空值                                                                                                                                                    |
| 关联产品   | 项目未完成：  <br>查询项目关联开发产品管理的sku数，点击数字可以超链接至开发产品管理并查询该项目编号的sku  <br>  <br>项目已完成：  <br>查询项目关联产品管理的sku数，点击数字可以超链接至产品管理并查询该项目编号的sku                                                                |
| 进度状态   | 状态为待启动：  <br>默认为正常  <br>当前日期>预计开始时间（日期)，则状态为逾期  <br>  <br>状态为进行中/已完成：  <br>按目前最新进行中的主线节点的【实际完成时间】、【预计完成时间(初始)】对比，若拿不到【实际完成时间】，则已当前时间计算  <br>>0则是逾期  <br>  <br>状态为已废弃：  <br>空值               |
| 逾期天数   | 状态为待启动：  <br>【当前日期】-【预计开始时间(初始)】  <br>  <br>状态为进行中/已完成：  <br>按目前最新进行中的主线节点的【实际完成时间】-【预计完成时间(初始)】，若拿不到【实际完成时间】，则已当前时间计算  <br>  <br>状态为已废弃：  <br>空值                                           |
| 项目日志   | 展示项目日志数量  <br>鼠标移入某行的时候显示"添加项目日志"按钮，点击则弹出新建项目日志的界面  <br>默认预填"项目节点"，若无则不预填                                                                                                                   |
