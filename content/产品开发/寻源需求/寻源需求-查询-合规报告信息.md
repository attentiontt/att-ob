# 寻源需求-查询-合规报告信息

### 业务规则

入口：从「寻源需求」列表点击【合规报告】数量，打开「合规报告」弹窗。

展示逻辑：「合规报告」弹窗展示合规报告筛选区、合规报告列表和操作列。

展示逻辑：点击「重置」时清空筛选项，具体是否立即刷新列表待确定。

展示逻辑：点击「更多」展示菜单「上传」「日志」。

展示逻辑：「上传」「日志」仅在原型中出现入口，未展开字段、校验、执行规则，不单独创建操作文档。

### 筛选项

【报告名称】单选选择器，默认空
【产品分类】单选选择器，默认空
【材质】单选选择器，默认空

### 列表数据

【报告名称】展示合规报告名称，示例「ROHS 2.0报告」「人造板小气候箱甲醛释放量检测」
【产品分类】展示报告适用产品分类，示例「PVC相框」「MDF置物架」「MDF相框」
【要求测试机构】展示要求测试机构，示例「SGS」「PFS」
【材质】展示材质，示例「PS」「MDF」
【报告要求】展示报告要求
【备注】展示备注；无备注时展示「-」
【报告跟进人】展示报告跟进人
【关联商品】展示关联商品数量
【状态】展示合规报告状态
【操作】展示「详情」「更多」

### 状态枚举

| 状态 | 说明 |
| --- | --- |
| 待上传 | 合规报告待上传 |
| 待审批 | 合规报告待审批 |
| 已上传 | 合规报告已上传 |
| 已驳回 | 合规报告已驳回 |

### 操作入口

【详情】点击后展示合规报告详情，具体详情字段、校验、执行规则待确定
【更多】点击后展示「上传」「日志」菜单
【上传】仅出现入口，上传字段、校验、执行规则待确定
【日志】仅出现入口，日志展示字段、查询规则待确定

### 不在范围内

不创建「上传」操作文档。
不创建「日志」查询或操作文档。
