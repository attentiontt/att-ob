# 导出-发票资料

### 业务规则

入口：从「头程发货单」列表点击「导出发票资料」或「导出发票」
导出范围：只支持单个头程发货单导出多发票
导出文件：xlsx名称格式为 `{运单号}-{箱数}箱-发票`

### 导出字段

基础信息
【编号】取调柜单明细编号
【发货单号】取调柜单信息发货单号
【运单号】取发货单号的运单号
【Msku】字段描述
【品牌brand】取产品库SKU基础信息品牌
【型号model number】取产品库SKU物流信息规格型号
【店铺】取Msku店铺
【国外海关编码 HS Code】取产品库SKU物流信息清关编码
【中文品名 Name (Chinese)】取产品库SKU物流信息清关中文品名
【英文品名 Name (English)】取产品库SKU物流信息清关英文品名
【产品图片 photo】取产品库SKU主图url
【数量(套) TOTAL QTY/PCS】取调柜单信息Msku数量
【清关单价 USD/Unit value】取产品库SKU物流信息清关申报单价
【清关总价值 USD/Total amount】等于清关单价×数量
【材质 material】取产品库SKU物流信息清关材质
【用途 function】取产品库SKU物流信息清关用途
【带电否】产品库SKU特殊属性勾选含电或纯电时展示「带电」，否则展示「不带电」
【箱数 quantity (CTN)】取调柜单信息
【总毛重 Gross Weight (KG)】取调柜单信息
【总净重 Net Weight (KG)】取调柜单信息
【货物尺寸 CARGO SIZE L(cm)×W(cm)×H(cm)】取产品库SKU包装信息整箱成品尺寸
【体积 CBM】等于整箱成品尺寸×箱数
【SHIPMENT ID】目的仓为沃尔玛或亚马逊时取货件编号，目的仓为三方仓时取货件编号，为空则无值
【REFERENCE ID】目的仓为亚马逊时取亚马逊REFERENCE ID，沃尔玛和三方仓无值
【仓库地址 warehouse address】取目的仓详细地址
【仓库编码】取目的仓仓库代码
弹窗可编辑信息
【整箱重量(KG)】数值输入框，只能输入正数，最多2位小数，默认从调柜单预填
【整箱成品尺寸(CM)】数值输入框，只能输入数值，点击刷新从产品管理拉取
【体积(CBM)】数值输入框，只能输入正数，最多2位小数，默认从调柜单预填
【清关单价】数值输入框，只能输入0或正数，最多2位小数，通过产品库物流信息清关单价预填，支持导入调整

### 点击导出时校验

校验1：按goodsid校验Msku清关编码、清关中文品名、清关英文品名、清关材质、清关用途是否有值；不满足提示：请检查sku：{sku1，sku2}清关编码、清关中文品名、清关英文品名、清关材质、清关用途是否有值
校验2：清关单价导入时校验表头是否包含【编号】【清关单价调整后】；不满足提示待确定
校验3：清关单价导入时校验【编号】是否属于该头程发货单对应调柜单明细；不满足提示：第x行编号与头程发货单不符，请确认
校验4：清关单价导入时校验【清关单价调整后】是否为0或最多2位小数的正数；不满足提示：第x行清关单价调整后只能输入0或正数，小数点最多两位
校验5：后端校验当前用户是否有导出权限；不满足提示：无权限导出

### 通过校验后执行

执行1：展示确认清关单价弹窗，允许修改每个Msku单品体积、单品重量、清关单价等导出信息
执行2：生成发票xlsx文件
执行3：若勾选【更新清关单价】且头程发货单状态为「待分配」「待订舱」「待提货」，自动刷新关税和关税手续费的计提金额，不刷新费用标准
执行4：关税费用项和关税手续费费用项不允许手工修改，由导出发票触发计算
执行5：记录导出日志

### 异常场景

导入模板顺序与导出发票不一致：原型要求导出数据顺序必须一致，处理规则待确定
税率取不到：关税或增值税计算规则待确定
重复点击：只执行一次或提示处理中，规则待确定

### 不在范围内

不支持批量多个头程发货单导出同一发票
