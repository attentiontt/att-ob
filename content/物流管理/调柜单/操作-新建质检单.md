# 操作：新建质检单

### 业务规则

入口：从「调柜单」点击「新建质检单」

展示逻辑：当调柜单为「变更中」时，展示「变更中」标签，且不生成质检单，自动跳过。

当【生产供应商】等于【出货供应商】时，基于调柜单明细 goods id 对应的【实际调柜数】，从状态为「待到货」的采购单明细中按相同 goods id 查询【本次质检量】；取值必须满足「生产供应商 + 采购主体」一致。
当【生产供应商】不等于【出货供应商】时，基于调柜单明细 goods id 对应的【待建质检数】，将【本次质检量】等于【待建质检数】后直接生成质检单，创建成功后扣减【待建质检数】。
质检单类型为「标签质检」时，不关联采购单；该质检单完成后不生成入库单，完成后执行锁库存动作。

### 点击提交/确定时校验

校验1：当【生产供应商】等于【出货供应商】时，若【本次质检数】不等于【实际调柜数】，对应调柜单明细展示「质检量不足」标签，不生成质检单并自动跳过
校验2：当【生产供应商】不等于【出货供应商】时，审批通过时从批次库存取值必须满足「生产供应商 + 采购主体」一致

### 通过校验后执行

执行1：满足条件的明细生成质检单，初始状态为「待质检」
执行2：不满足条件的明细自动跳过
执行3：记录操作日志
