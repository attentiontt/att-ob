# 操作：导入调柜单明细

### 业务规则

入口：从「调柜单列表」或「新建/编辑调柜单」点击「导入」

字段与校验
【销售平台】必填，校验顺序 1，校验格式是否为销售平台 code，即 amazon、walmart、tiktol；不满足提示：销售平台不存在
【目的国】必填，校验顺序 1，校验中文名是否存在于国家表；不满足提示：目的国不存在
【店铺】必填，校验顺序 1，校验店铺格式；不满足提示：店铺不符合格式
【Msku】必填，校验顺序 2，校验 Msku + 销售平台 + 目的国 + 店铺是否能在产品库启用 SKU 中查询到；不满足提示：Msku+销售平台+目的国+店铺不存在
【调柜数】必填，校验顺序 3，只能输入正整数且只能为整箱数；不满足提示：请输入正确的调柜数/调柜数只能为整箱数
【货件编号】非必填，校验顺序 4，基于货件编号 + Msku + 销售平台 + 调柜数汇总后匹配货件；若货件明细与调柜明细汇总一致，则导入成功并关联货件；不存在或不一致时不导入，提示：货件信息不匹配
【计划编号】必填，校验计划编号是否正确；不满足提示：计划编号填写不正确
【生产供应商编号】必填，校验是否为启用供应商；不满足提示：供应商编号不存在或未启用
【出货供应商编号】非必填，校验是否为启用供应商；为空时默认等于【生产供应商编号】
【装柜供应商编号】必填，校验是否为启用供应商；不满足提示：装柜供应商编号不存在或未启用
【出货供应商提货方式】导入时默认预填【出货供应商】默认出货提货方式
【装柜供应商提货方式】导入时按装柜供应商仓库与调柜单发货区域是否一致预填；未维护默认提货方式时提示：第x行供应商{供应商}未维护默认提货方式
【采购主体】必填，导入时默认填充生产供应商的默认采购主体
【报关退税】必填，校验值是否为「是」「否」；不满足提示：报关退税只能为是或否
【是否商检】从 goods id 找到 SKU 后取【是否商检】填入明细；SKU 未维护时提示：第x行sku{sku}未维护是否商检
【货好时间】必填，校验格式 yyyy-mm-dd hh:mm:ss；不满足提示：日期格式只能为yyyy-mm-dd hh:mm:ss
【发货区域】必填，校验仓库类型为「自营仓」且启用；不满足提示：仓库不存在或未启用
【目的国家】根据目的仓自动赋值，无需导入
【目的仓类型】根据目的仓自动赋值，无需导入
【目的仓】当目的仓类型为 FBA/WFS 时非必填，当目的仓类型为三方仓时必填；校验是否为启用仓库；不满足提示：仓库不存在或未启用
【运输方式】必填，校验是否为启用运输方式；不满足提示：运输方式不存在或未启用
【平台官方物流】根据运输方式自动赋值，无需用户导入；运输方式未维护时提示：第x行运输方式未维护平台官方物流
【柜型】必填，校验是否为启用柜型；不满足提示：柜型不存在或未启用
【散货拼整柜】非必填，为空默认「否」；有值时校验是否为「是」「否」；不满足提示：散货拼整柜只能填写是、否
【最晚提货时间】必填，导入时根据计划编号在补货日志中取【发货日期】赋值
【备注】非必填，最多 500 个字符；不满足提示：备注不能超过500位字符

### 通过校验后执行

执行1：导入并生成调柜单明细
执行2：可匹配货件时同步关联货件
执行3：自动填充供应商、采购主体、提货方式、目的国家、目的仓类型、平台官方物流、最晚提货时间等派生字段
执行4：重新计算调柜单汇总数据
