# 操作-编辑Case ID

### 业务规则

入口：从「FBA费异常列表」点击或编辑【Case ID数】。
展示逻辑：【Case ID数】不受状态限制，可随时编辑。
当用户编辑Case ID时，弹出「Case ID」弹窗。

基础信息
【异常单号】展示。
【状态】展示。
操作信息
【Case ID】文本输入框，默认空，最多20位。

### 点击提交/确定时校验

校验1：前端校验【Case ID】最多20位；不满足提示文案待确定。
校验2：后端校验当前用户是否有编辑权限；不满足提示「无权限操作」。

### 通过校验后执行

执行1：保存【Case ID】。
执行2：更新【Case ID数】，统计口径待确定。
执行3：记录Case ID编辑日志。

### 异常场景

【Case ID】为空时是否允许保存待确定。
多个Case ID的录入方式待确定。
重复点击：处理方式待确定。

### 不在范围内

不在本操作内同步亚马逊Case状态。
