### 流程说明
```mermaid
stateDiagram-v2

    [*] --> 待打样
    待打样 --> 待到样 : 打样
    待打样 --> 类型判断 : 到样
    待到样 --> 类型判断 : 到样

    类型判断 --> 待初样确认 : T1样品
    类型判断 --> 待评估 : T0/试模T0/更换供应商/竞品

    待初样确认 --> 待评估 : 初样确认通过
    待初样确认 --> 不通过 : 初样确认不通过

    待评估 --> 不通过 : 评估NG
    待评估 --> 类型判断2 : 评估Ok


    类型判断2 --> 待签样 : T1样品
    类型判断2 --> 已完成 : T0/试模T0/更换供应商/竞品

    待签样 --> 已完成

    不通过 --> 类型判断2 : 样品评估处复核

    已完成 --> [*]
```
