# 产品管理-SKU-操作-关联MSKU

### 业务规则

入口：从「新建产品」或「编辑产品」弹窗进入「商品信息」页签，点击「新建」「引用」「添加销售国」或「跟卖」相关入口

展示逻辑：商品信息用于维护 SKU 与 Msku 的关联关系。
展示逻辑：【Msku】自动生成且编辑时不可修改。
展示逻辑：源文件说明商品信息只展示原始 Msku，不展示引用的 Msku。
展示逻辑：引用功能的弹窗只展示满足条件的 goods id，引用后目的国不允许调整，必须与被引用数据一致。

操作信息
【Msku】置灰输入框，默认自动生成，生成规则为 SKU+平台两位字母+站点两位字母
【销售平台】单选选择器，默认空，必填，查出所有销售平台，编辑时不可修改
【目的国】单选选择器，默认空，必填，基于【销售平台】查询对应目的国，编辑时不可修改
【销售国】选择器，默认空，必填，基于【销售平台】查询支持的销售国
【店铺】单选选择器，默认空，必填，基于【销售平台】+【目的国】以及满足品牌对应的店铺查询，编辑时不可修改
【商品分级】单选选择器，默认空，非必填，选项待确定
【配送方式】选择器，默认空，非必填，控件类型待确定
【运营员】单选选择器，默认空，非必填，选项为「运营员」

### 点击提交/确定时校验

校验1：前端校验必填字段是否已填写；不满足提示待确定
校验2：后端校验【销售平台】【目的国】【销售国】【店铺】是否存在有效匹配关系；不满足提示待确定
校验3：后端校验同平台同站点是否已存在首个 Msku；存在时按跟卖序列生成
校验4：引用 goods id 时，后端校验 goods id 的销售平台是否为「Amazon」；不满足不展示或不允许引用，提示待确定
校验5：引用 goods id 时，后端校验 goods id 状态是否为「在售」；不满足不展示或不允许引用，提示待确定
校验6：引用 goods id 时，后端校验 goods id 的销售国对应商品维护 id 分级中是否存在任意一个非「停售」「清货」的数据；不满足不展示或不允许引用，提示待确定
校验7：后端校验当前用户是否有维护 Msku 关联权限；不满足提示「无权限操作」

### 通过校验后执行

执行1：生成或更新 SKU 与 Msku 的关联关系
执行2：首个同平台同站点 Msku 按 SKU+平台两位字母+站点两位字母生成，原型示例为「SVM0001AMUS」
执行3：同平台同站点跟卖 Msku 按 SKU+平台两位字母+站点两位字母+「-序列号」生成，序列号根据平台和国家的跟卖次数向后排序，首次跟卖序列号为「1」
执行4：引用 goods id 时，保存引用关系，并保持引用目的国与被引用 goods id 一致
执行5：记录操作日志

### 异常场景

销售平台或目的国为空：不生成 Msku，提示待确定
店铺不满足品牌或目的国规则：不允许保存，提示待确定
重复点击：只执行一次或提示处理中，具体提示待确定

### 不在范围内

Msku 独立详情、上下架、停售、清货、商品维护生命周期不在本文件展开
