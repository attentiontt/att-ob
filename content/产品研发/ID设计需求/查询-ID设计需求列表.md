# 查询-ID设计需求列表

### 列表数据

【图片】展示研发项目图片
【研发项目名称】展示研发项目名称
【研发项目编号】展示研发项目编号
【项目编号】展示项目编号
【模具类型】展示「新模」「复制模」「迭代模」等模具类型
【开发员】展示研发项目开发员
【项目经理】展示研发项目经理
【ID设计师】展示 ID 设计负责人
【结构工程师】展示结构设计负责人
【ID设计难度】展示「高」「中」「低」
【需求创建时间】展示需求创建时间
【预计初版方案完成时间】展示预计初版方案完成时间
【实际初版方案完成时间】展示实际初版方案完成时间，未完成时展示「-」
【提交完整方案时间】展示首次提交完整方案时间，未提交时展示「-」
【预计完整方案完成时间】展示预计完整方案完成时间
【实际完整方案完成时间】展示确认方案时间，未确认时展示「-」
【预计更新时间】有手板时取手板样节点开始后的预计手板认证时间，无手板时展示空
【实际更新时间】展示提交更新方案时间，未更新时展示「-」
【状态】展示当前 ID 设计需求状态
【操作】按状态展示「详情」「更多」「日志」「提交初版方案」「提交完整方案」「确认方案」「更新方案」

### 筛选项

【状态页签】单选选择器，默认「全部」，选项为「全部」「待提交」「待确认」「已确认」「已废弃」「待更新」「已完成」
【搜索字段】单选选择器，默认「研发需求编号」，选项为「研发需求编号」「研发项目名称」「项目编号」
【搜索关键字】文本输入框，默认空，占位提示「请输入搜索关键字」
【模具类型】单选选择器，默认空
【日期字段】单选选择器，默认「需求创建时间」，选项为「需求创建时间」「预计初版方案完成时间」「实际初版方案完成时间」「提交完整方案时间」「预计完整方案完成时间」「实际完整方案完成时间」「预计更新时间」「实际更新时间」
【日期范围】日期范围选择器，默认空，占位提示「开始日期 - 结束日期」
【人员角色】单选选择器，默认「ID设计师」，选项为「ID设计师」「结构工程师」「开发员」「项目经理」
【人员】单选选择器，默认空，占位提示「请选择」

### 页面操作

点击「重置」时，清空筛选项并恢复默认查询。
点击「详情」时，打开「ID设计详情」弹窗。
点击「更多」时，按状态展示可执行操作。
