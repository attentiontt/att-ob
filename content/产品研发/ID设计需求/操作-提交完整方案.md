# 操作-提交完整方案

### 业务规则

入口：从「ID设计需求列表」状态为「待提交」或「待确认」的数据点击「更多」后点击「提交完整方案」
展示逻辑：打开「提交完整方案」弹窗，展示「取 消」「保存」「提交」按钮。
当用户点击「保存」时，仅保存当前填写内容，不推进状态。
当用户点击「提交」时，系统提交完整方案。
操作信息
【完整方案源文件】附件上传，默认空，必填，支持扩展名 .rar、.zip、.doc、.docx、.pdf、.jpg 等，最多上传 3 份文件
【CMF】单选选择器，默认「需要」，必填
【CMF文件】附件上传，默认空，当【CMF】为「需要」时展示，支持扩展名 .rar、.zip、.doc、.docx、.pdf、.jpg 等，最多上传 3 份文件
【方案备注】文本输入框，默认空，非必填，不限制字符类型，最多输入 500 个字符

### 点击提交/确定时校验

校验1：前端校验【完整方案源文件】不能为空；不满足提示：请上传完整方案源文件
校验2：前端校验附件数量不能超过 3 份；不满足提示：最多上传3份文件
校验3：后端校验单据状态是否为「待提交」或「待确认」；不满足提示：当前状态无法提交完整方案
校验4：后端校验当前用户是否有操作权限；不满足提示：无权限操作

### 通过校验后执行

执行1：保存【完整方案源文件】【CMF】【CMF文件】【方案备注】
执行2：首次提交时记录【提交完整方案时间】为本次提交时间；重复提交时不覆盖首次提交时间
执行3：将状态变更为「待确认」
执行4：记录操作日志，操作内容为「提交ID设计需求完整方案：【XXX】从「a」修改成「b」」

### 异常场景

重复提交完整方案：允许多次提交，提交过一次后操作按钮展示为「保存」，方案内容更新为最新保存内容
附件格式不支持：不允许上传并提示支持的文件扩展名
方案备注超长：不允许提交，提示最多输入 500 个字符

### 不在范围内

不支持在「已完成」「已废弃」状态提交完整方案
