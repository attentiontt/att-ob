# 查询-ID设计需求操作日志

### 列表数据

【操作点】展示操作类型，示例为「提交」「确认」
【页面】展示业务页面，固定为「ID设计需求」
【操作人】展示实际操作人
【业务编号】展示研发需求编号
【操作内容】展示字段变更内容，格式示例为「提交ID设计需求初版方案：【XXX】从「a」修改成「b」」

### 筛选项

【业务编号】文本输入框，默认当前 ID 设计需求编号

### 详情

【操作点】展示
【页面】展示
【操作人】展示
【业务编号】展示
【操作内容】展示
【操作时间】展示系统记录时间

### 业务规则

入口：从「ID设计需求列表」或「ID设计详情」点击「日志」
展示逻辑：按当前 ID 设计需求编号查询操作日志，按操作时间倒序展示。
当用户提交初版方案、提交完整方案、确认方案或更新方案时，系统自动生成对应操作日志。
