# 提交模具-操作-新建模具

### 业务规则

入口：从「提交模具信息」弹窗点击「新建模具」，或在「物料信息」行点击「新建模具」。

展示逻辑：弹出「新建模具」弹窗，系统自动生成【模具编号】，保存后将新模具加入当前「模具信息」列表。

基础信息
【状态】单选选择器，默认「待制作」，必填，可选「待制作」「闲置」「停用」「量产」
【生产啤机吨位】数值输入框，默认空，非必填，单位「T」
【模具寿命】数值输入框，默认空，非必填，单位「啤」
【备注】文本输入框，默认空，非必填
【预估模具单价】金额输入框，默认空，必填
【模具尺寸】数值输入框，默认空，非必填，按长、宽、高填写，单位「CM」
【壁厚】数值输入框，默认空，非必填，单位「mm」
【缩水率】数值输入框，默认空，非必填，单位「%」
【成型周期】数值输入框，默认空，非必填
【锁模力】数值输入框，默认空，非必填
【模具编号】自动生成，必填，不允许手工修改
【模具名称】文本输入框，默认空，必填
【模具类型】单选选择器，默认空，必填
【产品生产价格】金额输入框，默认空，非必填
【是否开回模具费】单选选择器，默认空，非必填
【是否退回发票】单选选择器，默认空，非必填
【模具材质】文本输入框，默认空，非必填
【DFM源文件】附件上传，非必填，支持 .rar、.zip、.doc、.docx、.pdf、.jpg 等格式，最多上传 3 份文件
关联物料
【物料sku】文本展示，默认空
【物料名称】文本展示，默认空
【模穴数】数值输入框，默认空，必填
【主物料】单选选择器，默认空，非必填
【操作】展示「移除」
供应与文件信息
【模具供应商】单选选择器，默认空，必填
【模具3D图纸】附件上传，非必填，支持 .rar、.zip、.doc、.docx、.pdf、.jpg 等格式，最多上传 3 份文件
【注塑工艺参数表】附件上传，非必填，支持 .rar、.zip、.doc、.docx、.pdf、.jpg 等格式，最多上传 3 份文件
【注塑加工厂】单选选择器，默认空，必填

### 点击提交/确定时校验

校验1：前端校验必填字段不为空；不满足提示：请完善必填信息
校验2：前端校验【关联物料】至少存在一条；不满足提示：请新增关联物料
校验3：前端校验上传文件格式和数量；不满足提示：文件格式或数量不符合要求
校验4：后端校验【模具编号】唯一；不满足提示：模具编号已存在
校验5：后端校验当前用户是否有新建权限；不满足提示：无权限操作

### 通过校验后执行

执行1：生成模具主表记录
执行2：生成模具关联物料明细
执行3：保存附件信息
执行4：将新建模具加入当前「提交模具信息」的「模具信息」列表
执行5：记录操作日志

### 异常场景

重复点击：只创建一次，后续点击提示处理中
关联物料被移除为空：不允许保存，提示请新增关联物料

### 不在范围内

不支持在「新建模具」弹窗中修改结构设计工程 BOM。
